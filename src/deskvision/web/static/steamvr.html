FIRST WINDOWS RUN

Windows 接入顺序

  1. 启动 Windows 的 MikoType，使用终端打印的实际端口（9000–10000）。不要打开被其他软件占用的旧地址。
  2. 按项目 integrations/steamvr/README.md 构建、安装键盘驱动和 Bridge。需要 Windows、SteamVR、OpenVR SDK 和 C++ 构建工具。
  3. 下载当前键盘资源，按说明更新驱动的 render model。校准或布局改变后，请重新导出资源。
  4. 下载本次服务的 Bridge 凭证，再按说明启动 Bridge。服务重启后需要重新下载凭证。
  5. 打开 SteamVR Home，调整下方空间位置；确认后开启显示，再把头显中的实际结果反馈到日志。

MANUAL STANDING-SPACE ALIGNMENT

键盘在 VR 空间中的位置

正在读取位置

使用 SteamVR 站立参考空间，单位为米和度：+X 向右、+Y 向上、−Z 向前。默认 Pitch −90° 将模型的 XY 平面放平；组合旋转矩阵为 Ry(Yaw) × Rx(Pitch) × Rz(Roll)。

这是手动固定的空间位置，不会随现实键盘自动移动。移动键盘或重置 SteamVR 房间坐标后必须重新对齐。先确认画面位置，再尝试实际触碰；不要凭虚拟模型盲目伸手。

# Windows VR Client

This directory remains a production boundary marker only. No SteamVR/OpenVR
runtime code has been promoted into the V0.1 product here.

The isolated source-only feasibility work lives under
[`demo/steamvr_home_hybrid`](../demo/steamvr_home_hybrid/README.md). Its Mac
asset checks, fixed-pose GenericTracker source, and static Overlay smoke do not
count as a Windows runtime or production implementation. Promotion into this
directory requires Windows x64 + SteamVR + HMD acceptance first.
